# Observatory

Observe. Understand. Predict. Optimize.

Observatory is a terminal-first infrastructure command center built for homelabs, media servers, and Linux systems.

Unlike traditional monitoring tools that only show metrics, Observatory focuses on understanding your infrastructure. It combines real-time monitoring, historical analytics, Docker awareness, power and cost tracking, health scoring, forecasting, and actionable insights into a single keyboard-driven dashboard.

Features:

- Real-time system monitoring
- Docker health and container analytics
- Power usage estimation and cost tracking
- Historical metrics and trend analysis
- Infrastructure health scoring
- Storage intelligence and capacity forecasting
- Network monitoring and anomaly detection
- Alerting and recommendations
- Keyboard-first Textual interface
- Built for 24/7 operation

Observatory aims to be the command center every homelab owner wishes came built into Linux.







⚠️ Observatory is currently in active development. Version 1 establishes the platform, dashboard architecture, monitoring engine, analytics pipeline, and navigation system. Future releases will focus on dashboard refinement, insight quality, theme improvements, and overall user experience.
